MAPPA FUNZIONI qcmap_fcgi 01.11 (sha256 ade3017aaf3ef7…, analysis/device-pull-0111/qcmap_fcgi; indirizzi validi solo per questo binario):
- Login doLogin (0x1be88): confronta l'MD5 inviato dal browser con /bmdefsys/www/lighttpd.user ("admin:<md5hex>"); token di 32 char da /dev/urandom solo in memoria; record /www/qcmap_session 31 B = tv_sec, tv_usec, IP (16 B), timeout, etichetta (NIENTE token); cookie Set-Cookie qSessId=<token>; anti-bruteforce /www/login_attempt. Check: doCheckAuth 0x1c80c (IP + token + timeout), parser_CheckAuth 0x1b834 (login.cgi POST check_valid=qSessId=...). authID: refreshToken 0x1c954 (6 cifre, loggato in syslog).
- doGetWhoAmI (capability per la UI): 0x1cc8c — emette JSON system_support con wifi_guest_ap:0, samba_support:0, wifi_support_5G:0, no_LTE:0, ethernet:0, battery_support:1 (hardcoded). Per far comparire sezioni UI nascoste (es. guest AP) si può patchare questi 0→1, ma le funzioni vanno comunque abilitate lato sistema.
- Wi-Fi apply: 0x16a94 — scrive i MIB per-interfaccia con FUN_000161e8("wlan0",<chiave>,<val>) in /var/rtl8192c/wlan0/<chiave>, poi system("/bmdefsys/usr/bin/rtltools/script/init.sh &"). Getter Wi-Fi (legge countrycode dal file): 0x16294/0x31214. Helper lettura MIB: FUN_00016110(iface,chiave,buf,len).
- bm_config.conf: lettura 0x18ca4 (cerca "Country_code=" ecc.), scrittura 0x19fac (fprintf "Country_code=%s"). API webpost bm_wlan_countrycode: scrive /var/rtl8192c/wlan0/countrycode (NON bm_config). Il country regolatorio del radio dipende dal MIB countrystr (set in wlan_8192c.sh), non da bm_config Country_code.
- AP-STA: JSON on_integer 0x5003c (apsta_turnon, wifi_channel, ap_mode, bm_network_id, bm_wep_index, bm_wep_type), on_string 0x50164 (bm_bssid, bm_ssid, bm_encrytion, bm_password), wifi_mode 0x50718, add_network 0x51fe8.
